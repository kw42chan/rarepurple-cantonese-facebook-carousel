# Worked example: use case #11 長文件摘要

Source retained: Card 01 長文件摘要 / Doc Summarisation. Scenario: 收到20頁行業報告或合約，需在5分鐘內掌握重點。 Prompt: 將以下報告摘要為5個重點，每點不超過30字；再逐點展開解釋。[上傳PDF]. Benefits: 5分鐘掌握重點、壓縮為5個要點、3分鐘完成閱讀.

## 7-page storyline

1. 「15 頁合同，半個鐘內要口述」 — stressed worker, PDF, papers, coffee, clock.
2. 「逐頁讀，讀完個鐘都冇咗」 — document pile and disappearing time.
3. 「老細一問，個腦一片空白」 — meeting questions about points, risks, and next steps.
4. 「3 步，由長文件變清晰重點」 — 貼文件 → 出摘要 → 標風險.
5. 「15 頁迷霧」 versus 「1 頁清晰」 — qualitative comparison only.
6. 「有重點，開會有底氣」 — concise summary and tea break.
7. 「拍到『長文件摘要』呢張卡，跟住做就有底氣」 — product card CTA.
