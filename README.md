# rarepurple-cantonese-facebook-carousel

Reusable Agent Skill for creating premium Cantonese Facebook/Instagram carousels for AI 拍拍機 and Hong Kong office audiences.

## What it produces

- A 6–7 page narrative carousel.
- Page-by-page image prompts with exact artwork copy.
- A recurring premium 3D East Asian female office-worker character.
- A deep royal-purple and metallic-gold visual direction.
- A Facebook-optimized Cantonese caption with hook, story, AI solution, transformation, CTA, hashtags, and a comment-driving question.

## Package map

- `SKILL.md`: entrypoint and workflow.
- `references/`: visual, character, structure, and caption rules.
- `prompts/`: reusable page prompt templates.
- `examples/`: source-grounded worked example for use case #11 長文件摘要.
